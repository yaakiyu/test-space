# Cプログラミング入門 第2回レポート ソースコード保管所
ここでは第2回レポートで使用したソースコードを保管しています。

## 各ファイルの説明
- `a.c` ... 問題1「巨大数の加算」
- `b.c` ... 問題2「モンテカルロ法で円周率」
- `c_1.c` ... 問題3「予算内で満足度最大の買い物」
- `others/` ... 直接レポートには載せていないコード
  - `a_sub.c` ... 問題1と同等の方法で引き算を実装したもの
  - `b_auto.py` ... 問題2において表を作成するために使用したpythonスクリプト
  - `b_modified.c` ... 問題2において表を作成するために出力内容の調整と乱数初期化の方法変更を行ったもの
  - `b_output.txt` ... `b_auto.py`を利用して得た出力結果
  - `c_fastest.c` ... 問題3を最適戦略に基づいて実装したもの
  - `c_check.py` ... `c_fastest.c`の出力が正しい(`c.c`と一致する)ことを検証するためのpythonスクリプト
