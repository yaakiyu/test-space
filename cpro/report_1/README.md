# Cプログラミング入門 第1回レポート ソースコード保管所
ここでは第1回レポートで使用したソースコードを保管しています。

## 各ファイルの説明
- `a.c` ... 問題1「うるう年」
- `b.c` ... 問題2「ピタゴラス数」
- `c_1.c` ... 問題3「平方和」の方法1
- `c_2.c` ... 問題3「平方和」の方法2
- `others/` ... 直接レポートには載せていないコード
  - `b_old.c` - 問題2「ピタゴラス数」で使わなかったコード1。二分探索を使用
  - `b_old_2.c` - 問題2「ピタゴラス数」で使わなかったコード2。高速整数平方根求値アルゴリズムを使用
  - `c_ll_1.c` - 問題3「平方和」の方法1でlong long型を使用した場合のコード
  - `c_ll_2.c` - 問題3「平方和」の方法2でlong long型を使用した場合のコード
  - `checker.sh` - 問題2「ピタゴラス数」で速度を測定するために使用したスクリプト。同時に`b_old.c`の速度も測定する
- `README.md` - このファイル
